# Noto

Source fonts that test fonts borrow glyph outlines from. Nothing in the book shapes with them directly.

* `NotoNaskhArabic-Regular.ttf`, version 2.021, from notofonts.github.io (`fonts/NotoNaskhArabic/hinted/ttf/`, commit cb61ee554, 2026-01-17).
* `NotoSansDevanagari-Regular.ttf`, version 2.007, from notofonts.github.io (`fonts/NotoSansDevanagari/hinted/ttf/`, commit 92d2ea744, 2026-09-10).

Both are by the Noto Project Authors, under the SIL Open Font License 1.1: see `OFL.txt`. Latin outlines come from Libre Baskerville, in `fonts/quick-start/`.
