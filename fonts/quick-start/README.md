# Libre Baskerville

`LibreBaskerville.ttf` is `LibreBaskerville[wght].ttf` from Google Fonts (google/fonts, `ofl/librebaskerville/`, commit 9e63336c5 2025-10-17), renamed. It is by Impallari Type, under the SIL Open Font License 1.1: see `OFL.txt`. It's a variable font (weight 400 to 700), and the quick start uses its default, 400.

It replaces Roboto in the quick start because it has the ligatures the examples show: `liga` has ff, fi, fl, ffi and ffl, and `dlig` has ct, st, sp and the f ligatures with b, h, j, k and t.
