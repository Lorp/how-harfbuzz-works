# Bugs this book found

Writing this book meant building small fonts that exercise one thing each, shaping text with them, and checking every result against the code and the specifications ([Testing with a font of your own](testing-harfbuzz.html#testing-with-a-font-of-your-own)). Some results didn’t match. Those are drafted as bug reports in [`notes/upstream-bug-reports.md`](https://github.com/Lorp/how-harfbuzz-works/blob/main/notes/upstream-bug-reports.md), in the book’s repository, eighty-three so far, each reproduced on HarfBuzz {{hb}} (commit `3df40d9b`), most with a font or a command that needs nothing from this book. This appendix lists them all. What they suggest about where bugs are left to find is in [Where the bugs are](testing-harfbuzz.html#where-the-bugs-are).

**None is yet on HarfBuzz’s issue tracker.** The first sixty-five went to HarfBuzz’s author directly, and many are already fixed (see the last column below), but they are still drafts, written by the book’s authors. Some are certainly bugs, some are matters of policy that HarfBuzz’s developers may well decide the other way, and a few were found by reading code and have no example yet.

Each draft keeps its number for good, and its ID, such as HHW-75, is how HarfBuzz’s pull requests cite it (“How HarfBuzz Works bug 75”). A withdrawn draft keeps its number too.

The tables below give each draft’s number in that file, a one-line summary, the chapter that describes the behavior, and how it was checked:

* **Live.** The chapter shows the behavior in a block, built from HarfBuzz {{hb}} when the page is built.
* **Run.** Reproduced with HarfBuzz’s tools or a small program, but not shown live.
* **Read.** Found by reading the code.

The last column records what has happened upstream. Drafts 1–65 were shown to HarfBuzz’s author, Behdad Esfahbod, on 17 November 2026, and he fixed many of them on the `main` branch the same day. Drafts 1–82 were checked against `main` at commit `454f9c4` (17 November) on 18 November 2026, and draft 83 against `94715f6` (19 November) on 20 November, by rerunning its example or, for those found by reading, reading the code again. The column says “fixed”, with the pull request that fixed the draft (`notes/upstream-bug-reports.md` has the commits); “partly fixed” where some of a draft’s items are fixed; “changed” where the behavior is different but the problem remains; “in progress” where a pull request that addresses it is open but not merged; and “open” where the draft still describes `main`. Related issues come from a keyword search of HarfBuzz’s issues and pull requests, which isn’t exhaustive.
