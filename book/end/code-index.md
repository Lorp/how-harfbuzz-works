# Code index

HarfBuzz’s functions, types, macros, internal structs, and source files, sorted without their `hb_`, `HB_`, or `hb-` prefix. A number in bold marks the place a name is introduced. <span class="screen-only">Each link gives a chapter and its section (35.3 is chapter 35, section 3); letters are appendices.</span> Concepts and OpenType tables are in the [Index](general-index.html).

For HarfBuzz’s public API, the definitive account is its [API reference](https://harfbuzz.github.io/reference-manual.html), part of HarfBuzz’s own documentation: what each function does and promises, and since which version. Check it alongside the explanations and examples here, which describe HarfBuzz {{hb}}. Internal names aren’t in it; for those, the source is the authority.
