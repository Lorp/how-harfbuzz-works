# How HarfBuzz Works

**From Unicode to positioned glyphs, and everything in between**

A book about HarfBuzz, the text shaping engine used by Chrome, Firefox, Android, GNOME, LibreOffice and most other software that puts text on a screen. It’s written from HarfBuzz’s source code, version {{hb}}, and every example in it is run on that version.

This is a draft. Every chapter is written, but the book is still being checked and revised, so some details will change before it’s finished.
